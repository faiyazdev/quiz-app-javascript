# Quiz App

A simple, interactive multiple-choice quiz app. Users answer one question at a time, get instant visual feedback on their selection, and move to the next question using the **Next** button. A countdown timer keeps each question on the clock, and a progress bar tracks how far along the quiz you are.

**🔗 Live Demo:** [asgorfaiyaz.github.io/quiz-app-javascript](https://asgorfaiyaz.github.io/quiz-app-javascript)

## 🛠️ Built With

- **HTML** — page structure
- **CSS** — styling and layout
- **JavaScript (Vanilla)** — quiz logic and DOM manipulation

## ✨ Features

- Multiple-choice questions, one at a time
- Instant answer feedback (correct answer highlighted in green, wrong selection in red)
- 10-second countdown timer per question — auto-locks answers and reveals the correct one if time runs out
- Progress bar showing current question out of total questions
- Score tracking throughout the quiz
- High score saved to `localStorage` and displayed at the end
- "New High Score" celebration when you beat your previous best
- Restart/Play Again option to retake the quiz

## 📦 Dependencies

None — this project is built with plain HTML, CSS, and JavaScript (no frameworks or npm packages required).

## 🚀 Running Locally

No build step or installation needed.

1. Clone the repository
   ```bash
   git clone https://github.com/asgorfaiyaz/quiz-app-javascript.git
   ```
2. Navigate into the project folder
   ```bash
   cd quiz-app-javascript
   ```
3. Open `index.html` directly in your browser, or serve it with a local dev server (e.g. VS Code's Live Server extension) for the best experience.
